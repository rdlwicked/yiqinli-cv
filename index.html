research interests

My research targets the scalability bottlenecks in robot learning — from building embodied AI agents that understand and act in the physical world, to creating autonomous training loops that reduce human supervision.

Embodied AI Agents

Building LLM/VLM-powered agents that understand natural language, reason about physical environments, and orchestrate robot behaviour through unified semantic interfaces.

Vision-Language-Action Models

Benchmarking and training VLA systems that unify visual perception, language understanding, and motor control within a single network for general-purpose manipulation.

Agent-in-the-Loop Learning

Replacing human supervision with autonomous VLM agents that detect failures, guide recovery, and generate dense reward signals to close the robot self-improvement loop.

Dexterous Manipulation

Developing teleoperation systems and end-to-end training pipelines for multi-fingered robotic hands, from data collection through sim-to-real deployment.

RoboClaw — Embodied AI Assistant

Embodied AI · LLM Agent · ROS2 · Open Source · 174 Stars

An open-source framework for embodied AI assistance that enables natural-language control of robots. Features a unified semantic interface across different robot platforms, an agent layer for dialogue and procedure selection, and an end-to-end ROS2 execution pipeline supporting both simulation and real-robot deployment.

GitHub

Dexterous-Hand VLA Pipeline

VLA · Dexterous Hand · Real Robot · ROS2 · Ongoing

Building a complete pipeline for dexterous manipulation at Shanghai Jiao Tong University: a teleoperation system integrating LinkerHand O6 and xArm6 via ROS2 with a UDCAP glove, a lightweight VLA model adapted for 22-DoF arm-hand coordination, and systematic evaluation from simulation to real-robot deployment.

Language-Guided Imitation Learning

Imitation Learning · LLM Planning · PyBullet · Franka Panda · MEng Thesis

MEng thesis at Imperial College London: a closed-loop system where an LLM planner decomposes natural-language commands into a sub-task DAG, a behaviour-tree controller orchestrates perception and policy execution with automatic failure recovery, and an interactive interface lets non-expert users teach new behaviours on the fly. Achieved 100% on pick-and-place, 2.4× improvement vs code-as-policy baseline.
